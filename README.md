# WHO Website (1st Semester Project)

This repository contains a static website developed as part of my first-semester CSIT coursework at Nepathya College. The project focuses on creating a responsive and accessible website for the World Health Organization (WHO), utilizing HTML and CSS.

## Project Overview

The WHO Website project aims to replicate a professional WHO page, emphasizing clean design, usability, and responsiveness. It serves as an excellent exercise in applying foundational web development skills.

## Features

- **Responsive Design:** Optimized for various screen sizes, ensuring usability across devices.
- **Semantic HTML:** Proper use of HTML5 elements for structure and accessibility.
- **CSS Styling:** Clean and organized CSS for layout and design consistency.

## Technologies Used

- **HTML5**
- **CSS3**

## File Structure

- `whowebsite.html`: The main HTML file containing the website's structure.
- `who.css`: The primary CSS file for styling the website.
- `dropdown.css`: Additional CSS for dropdown menu styling.
- `download.jpg`: Image asset used within the website.
